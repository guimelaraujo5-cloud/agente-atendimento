# Matriz E2E por produto

- INSS: triagem (aposentado/pensionista + empréstimo atual) -> consentimento -> name/cpf/birth_date -> handoff.
- FGTS: saque-aniversário + saldo + mês aniversário -> consentimento -> handoff.
- CLT: CLT ativo + 6 meses -> consentimento -> handoff.
- CARTAO: limite + parcelas + banco -> consentimento -> handoff.
- AUXILIO_BRASIL: recebe benefício + contrato ativo + valor >= 400 -> consentimento -> handoff.
